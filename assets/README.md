# GT2-Vita Game Data

GT2-Vita is a native PlayStation Vita sourceport of Gran Turismo 2.

The Vita executable does not include the original PlayStation 1 game data.

You must provide your own legally obtained copy of the Gran Turismo 2 PlayStation 1 game data.
